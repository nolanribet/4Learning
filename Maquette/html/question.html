Problème avec les pointeurs en C (Segmentation fault)

Bonjour, j'essaie de parcourir une liste chaînée mais je reçois systématiquement une erreur de segmentation quand j'atteins le dernier noeud. Voici un bout de mon code :

while(actuel->suivant != NULL) {
    printf("%d\n", actuel->valeur);
    actuel = actuel->suivant;
}
Informatique Langage C

Sarah L. [Mentor]

L3 Info • Il y a 45 min

Salut Thomas ! Ton erreur vient de ta condition `actuel->suivant != NULL`. Si `actuel` est déjà NULL, essayer d'accéder à `actuel->suivant` provoque un segfault. Essaie plutôt `while(actuel != NULL)`.
